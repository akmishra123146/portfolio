Vibe coding, security first

My checklist for any AI-assisted code before it is merged.

1. Human review of every diff

No blind accepts. I read each AI-generated change and rewrite anything I cannot explain.

2. Threat modelling first

Trust boundaries, abuse cases and data sensitivity are mapped (STRIDE) before features are built.

3. OWASP Top 10 checks

Input validation, parameterised queries, strong authN/authZ, rate limiting, CSRF/XSS protection and safe error handling.

4. Automated scanning in CI

SAST (Semgrep), dependency audits (npm audit / Snyk) and secret scanning (gitleaks) block risky commits.

5. Secrets and least privilege

No keys in code, environment-based config, scoped IAM roles and encrypted data at rest and in transit.

6. Tests, logs and safe rollout

Unit and integration tests for critical paths, audit logging, and staged releases with rollback.
